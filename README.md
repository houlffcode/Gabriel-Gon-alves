# Portal Institucional em HTML puro

Não exige Node.js, npm, React ou Vite.

## Abrir

Abra `index.html` diretamente ou use a extensão Live Server no VS Code.

## Personalizar

- Textos: edite os arquivos `.html`.
- Cores e responsividade: `assets/css/style.css`.
- Menu, animações e modais: `assets/js/main.js`.
- Imagens: `assets/images/`.

## Páginas

- index.html
- minha-trajetoria.html
- propostas.html
- agenda.html
- participe.html

## Responsividade

O CSS contém ajustes para desktop, tablet, mobile e telas de até 360 px.

## Novas seções

- Home: galeria de imagens com ampliação e chamada breve de participação.
- Minha trajetória: carrossel horizontal de vídeos.
- Propostas: visão geral, filtros de navegação, método, compromissos e materiais complementares.

Para trocar vídeos, altere os URLs dos `iframe` em `minha-trajetoria.html`.

## Galeria

A página `galeria.html` possui filtros por categoria, ampliação em tela cheia e navegação anterior/próxima. Para adicionar uma imagem, copie um bloco com a classe `gallery-photo`, altere o caminho e escolha a categoria em `data-gallery-category`.

## Minha trajetória

A página `minha-trajetoria.html` agora possui biografia, fatos rápidos, linha do tempo de cargos/campanhas/aprovações, realizações e carrossel de vídeos. Substitua todos os campos `20XX`, títulos e descrições pelos dados reais e inclua links de referência quando disponíveis.

## Agenda completa

A agenda possui evento em destaque, filtros, calendário visual, lista detalhada, botão para copiar informações e chamada para acompanhamento.

## Participe completo

A página possui opções de participação, área para Google Forms, canais externos, explicação de funcionamento, dúvidas frequentes e aviso de privacidade.
